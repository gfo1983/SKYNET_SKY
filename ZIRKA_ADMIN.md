# ZIRKA — інструкція для адміністратора

Встановлення відеопередавача SKYNET на малину ZIRKA (Raspberry Pi 5 з образом Zirka).
Потрібно: доступ до малини (SSH або консоль) з правами `sudo` і інтернет на малині.

## 1. Встановити софт (одна команда)

```
curl -fsSL https://raw.githubusercontent.com/gfo1983/SKYNET_SKY/main/zirka_install.sh | sudo bash
```

Займає 1–2 хвилини. Скрипт сам завантажить і перевірить софт, встановить і ввімкне його.
Ядро і софт Zirka не змінюються.

Наприкінці на екрані буде рамка:

```
  │  ІДЕНТИФІКАТОР ПРИСТРОЮ:  D86113115564365C18F1BAD463490124  │
```

## 2. Надіслати ідентифікатор постачальнику

Скопіюйте **ідентифікатор пристрою** (32 символи) і надішліть постачальнику.
Він привʼязаний до процесора саме цієї малини.
Забули — подивитись ще раз: `sudo wfb-id` (або файл `/root/ZIRKA_DEVICE_ID.txt`).

## 3. Активувати ключем від постачальника

Постачальник надішле **ключ активації** — один довгий рядок, що починається з `SKYACT1:`.
Виконайте на тій самій малині (ключ вставити повністю, в один рядок):

```
sudo zirka-activate SKYACT1:....
```

Має завершитись словами **«ГОТОВО: ZIRKA активовано»**.
Якщо написано «ЛІЦЕНЗІЮ НЕ ПРИЙНЯТО» — ключ не для цієї малини: перевірте, що надіслали правильний
ідентифікатор (`sudo wfb-id`), і зверніться до постачальника. Ключ від іншої малини не працює.

⚠️ Ключ активації — конфіденційний: не публікуйте і не передавайте його стороннім.

## 4. Звʼязати з наземкою (BIND)

1. На наземці: веб-інтерфейс → **BIND**.
2. Протягом 30 с **коротко** натиснути кнопку бінду на малині (GPIO24, пін 18 → GND).
3. На екрані наземки: «BINDING» → «OK» (або «UPDATING DRONE», якщо наземка оновлює софт борта) → відео.

## Корисне

- Стан: `systemctl status wfb-drone`, журнал: `journalctl -u wfb-drone -f`.
- Світлодіод (GPIO23): 100/900 мс — звʼязок з наземкою є; 1,5/0,5 с — нема ліцензії; 3 швидкі + пауза — потрібен BIND.
- Якщо після оновлення борт поводиться неправильно: **затиснути кнопку бінду на 15 с** — софт WFB повернеться
  до попередньої версії (світлодіод часто блимає), без перезавантаження малини.
