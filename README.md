# SKYNET_SKY — оновлення наземних станцій SKYNET

Тут лежать **лише готові релізи**: скомпільовані програми наземки та **зашифровані** пакети ПЗ дронів.
Вихідного коду тут немає.

Кожен реліз (`Releases`) містить:

| файл | що це |
|---|---|
| `gs-<версія>.tar.gz` | програми наземки (`bin/`), зашифровані пакети дронів (`drone_fw/*.fw`), `VERSION` |
| `manifest.json` | версія, контрольні суми файлів, версії пакетів дронів |
| `manifest.sig` | цифровий підпис маніфесту |

Наземка встановлює реліз **лише з правильним підписом** — підробити чи підмінити його неможливо.
Програми працюють тільки на наземці з ліцензією, привʼязаною до її процесора; пакети дронів зашифровані.

Оновлення: веб-інтерфейс наземки → «Системні» → «Оновлення ПЗ наземки» → «Перевірити оновлення» → «Оновити».
Перед оновленням наземка робить бекап; якщо щось пішло не так — кнопка «Відкотити на попередню».

## Оновлення старої наземки прямо на ній (без кнопки у вебі)

На наземці (потрібен інтернет), від root:
```
curl -fsSL https://raw.githubusercontent.com/gfo1983/SKYNET_SKY/main/gs_update.sh | bash -s update
```
Відкат на попередню версію:
```
curl -fsSL https://raw.githubusercontent.com/gfo1983/SKYNET_SKY/main/gs_update.sh | bash -s rollback
```
Стан (версія, остання операція, бекапи):
```
curl -fsSL https://raw.githubusercontent.com/gfo1983/SKYNET_SKY/main/gs_update.sh | bash -s status
```
Після першого оновлення у вебі наземки з'являється картка «Оновлення ПЗ наземки».

## Розгортання передавача ZIRKA (Raspberry Pi 5) однією командою

На новій малині ZIRKA (образ Zirka, потрібен інтернет):
```
curl -fsSL https://raw.githubusercontent.com/gfo1983/SKYNET_SKY/main/zirka_install.sh | sudo bash
```
Скрипт бере пакет `zirka-deploy-<N>.tar.gz` з останнього релізу, **перевіряє підпис релізу** і контрольну суму,
ставить драйвери RTL8812AU/EU + wfb-ng (готові під ядро Zirka; під інше ядро — збираються), wfbd, сервіси,
агент зміни каналу, кнопку (коротко = bind, 15 с = відкат) і резервний маршрут відео без кабелю.
Ядро, config.txt і софт Zirka не змінюються. Наприкінці показує ID плати для ліцензії.

Наприкінці скрипт покаже **ідентифікатор пристрою** (привʼязаний до процесора) — його надсилають постачальнику,
той видає **ключ активації**, і на малині: `sudo zirka-activate <КЛЮЧ>`.
Покрокова інструкція для адміністратора: **[ZIRKA_ADMIN.md](ZIRKA_ADMIN.md)**.

Секретних ключів у публічному пакеті немає — вони приходять разом із ключем активації.
